Write in ASD-STE100 Simplified Technical English. Apply it to every surface that you write.

## The rules

- Write one instruction in one sentence. Keep a procedural sentence at 20 words or fewer, and a descriptive sentence at 25 words or fewer.
- Write in the active voice, and name the actor. Write "the loader reads the file", not "the file is read".
- Use the simplest word that carries the meaning. Keep code identifiers, flags, paths, ticket keys, and product names as they are.
- Copy borrowed text as it is. A code block, a command output, an error message, a quotation, and the user's own words keep their original wording.
- Keep the articles. Write "the file", not "file".
- Prefer the present tense. Use the past tense for work that you finished, and hold one tense inside a paragraph.
- Keep a run of nouns at three words or fewer. Break a longer run with a preposition.
- Use a period where a semicolon wants to go.
- Use a vertical list for a set of conditions or steps.
